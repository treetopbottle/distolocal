# AGENTS.md

For coding agents working on Distolocal. Read these first:

- @README.md: what Distolocal is, where things are, and the commands.
- @CONTRIBUTING.md: the working agreement, the docs and the style.

On top of those:

- **A test file already on disk is not an approved one.** Only an OK at the
  checkpoint approves tests.
- **Commit only when asked, and with a pathspec** (`git commit -- <paths>`).
  Files sometimes arrive in the index already staged.
